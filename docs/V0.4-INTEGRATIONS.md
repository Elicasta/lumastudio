## ProPresenter

Studio uses the official ProPresenter network API as the primary presentation connection.

### Same computer

1. Enable ProPresenter Network/API access.
2. In Studio, open **Show → Integrations**.
3. Choose **This Computer**.
4. Confirm the ProPresenter API port. Studio defaults to `50001`.
5. Enable **ProPresenter API**.

### Different computers

Studio can connect directly to ProPresenter over the LAN.

1. Put both machines on the same network.
2. Enable ProPresenter Network/API access on the ProPresenter computer.
3. Enter that computer's IP in Studio, or run the updated LumaLink build there.
4. Choose **Find LumaLink on Network** in Studio.
5. Select the discovered machine.

LumaLink only performs discovery in this flow. Once selected, Studio talks directly to ProPresenter. Presentation control therefore does not depend on LumaLink staying open after the connection is established.

If UDP discovery is blocked by a firewall, enter the ProPresenter computer's IP manually.

## Presentation modes

Each Studio Song owns its presentation mode.

- **Manual**: Studio observes ProPresenter but sends no automatic presentation commands.
- **Section Follow**: Studio follows Song sections such as Verse, Chorus, and Bridge. Individual lyric slides remain manual.
- **Full Auto**: Studio follows sections and fires recorded slide cues from the Song timeline.

Old projects default to Manual.

### Safety behavior

Studio only auto-controls ProPresenter when the active ProPresenter presentation title matches the Studio Song title after normalization.

If ProPresenter is on another presentation, automatic commands are held.

When playback seeks or jumps forward, skipped slide cues are marked passed rather than fired in a burst.

### Recording slide cues

1. Open **Build → Presentation**.
2. Select **Full Auto**.
3. Start Song playback.
4. Select **Record Slide Cues**.
5. Tap **NEXT CUE** where each lyric slide should change.
6. Stop recording and review the captured cue list.
7. Use **Playback Lead** to shift all cues earlier or later without moving each cue.

When ProPresenter is connected and on the matching Song, tapping NEXT CUE also advances ProPresenter during rehearsal.

## Planning Center

Studio currently supports Planning Center Services Personal Access Tokens.

1. Open **Show → Integrations**.
2. Enter the Planning Center Personal Access Token App ID and secret.
3. Connect and choose a Service Type.
4. Choose an upcoming or recent Plan.
5. Preview the Plan before applying it.

Credentials are held in app memory for the current session and are not written into the Studio project file.

### Import behavior

Planning Center is treated as the service source, not as permission to destroy existing Studio work.

When a Planning Center Song matches an existing Studio Song by Planning Center ID or normalized title:

- existing stems are preserved
- section timing is preserved
- Studio BPM/timeline work is preserved
- video, lighting, MIDI, guide, and presentation work are preserved
- Planning Center IDs, key, and arrangement sequence are attached

A new Planning Center Song is imported as **Needs Review** with Planning Center metadata and placeholder sections.

The linked Plan snapshot also retains non-song service items for a later full service-rundown UI.

## LumaLink discovery protocol

LumaLink listens for UDP discovery on port `49777`.

Request:

`LUMALINK_DISCOVER_V1`

The response reports the node name, platform, app version, capabilities, and suggested ProPresenter port.

This is LAN-only discovery. It is not a cloud relay and does not proxy live ProPresenter commands.
