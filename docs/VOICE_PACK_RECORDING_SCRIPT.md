# Core English Voice Pack — Recording Script

Record every line as its own WAV file. Keep delivery concise, consistent, neutral, and dry.

A core pack is 44 files. Recording the same script with a second performer creates a completely interchangeable second voice.

## Delivery notes

Counts should sound related: One. Two. Three. Four. Do not make One dramatically more accented than the other numbers; the Click bus handles downbeat accent. Keep each number short enough to remain intelligible at faster tempos.

Section names should sound like stage directions, not announcements. Avoid rising question-like inflection.

Direction phrases should be decisive but not aggressive.

## Recommended takes

Record three takes of each token in one session. Select one coherent take per token. Do not randomly alternate takes at runtime in the first version; predictable timing is more valuable than vocal variation.
